# 仿真校准锚定在自家仿真仓，与 Olist 只做分布形状对照

仓内 SimPy 仿真是「拣货→复核→打包→出库」的分钟级作业流，而 Olist 履约是「下单→送达」的天级全链路（含跨境物流、审单、承运商、最后一公里）。两者绝对时长尺度相差几个数量级，直接做 KS 检验必然拒绝，且为通过 KS 而给仿真硬补「运输时长」假设会用情景假设污染仿真、违背「禁止把仿真表述为真实观测」的最高原则。

我们决定：仿真的校准锚点是**自家的仿真仓表（3.1）**——到达过程与 14–16 点效率低谷埋点相互印证，拣货/复核耗时与仿真仓出库单的时间字段对齐。与 Olist 的关系降级为**无量纲分布形状对照**：只比对变异系数 / 偏度，且只对尺度可比的子段（出库响应时长 = 发货−审单），**不做绝对时长 KS**。台账与报告显式登记「跨尺度，不做绝对时长 KS」这一已知限制。

## Consequences

- 验收标准里「完成与 Olist 的分布校准」一项，按本 ADR 解释为「形状对照 + 内部一致性校准」，而非绝对时长 KS 通过。
- 任何后续想给仿真补运输时长以撑大尺度的改动，都应在评审时被拦下——那是被刻意拒绝的方向。
