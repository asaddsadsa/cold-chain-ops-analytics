**Key interfaces:**
- 重量段口径（登记台账）：订单级重量 = 该订单所有 item 重量之和（kg）；分段 ≤0.5 / 0.5–1 / 1–3 / 3–10 / >10 kg；无重量数据的订单归「未知」段、不进重量时效分析；
- 准时口径：is_late = 实际送达 > 预计送达（已在 03 落盘），真实准时交付率 = 1 − 延迟率，边界「实际送达 == 预计送达」算准时；
- reviews 交叉：一单可有多条评论，取该订单评论均分；差评率 = review_score ≤ 2 占比；
- 下钻函数接受 DataFrame 返回分组统计 DataFrame，纯函数可单测。

### 实现记录（2026-09-13）

**产出**：`src/olist_kpi.py`（KPI 纯函数可独立调用：real_ontime_rate/real_delay_rate/add_order_weight/三维 drilldown/weight_time_relationship/review_cross_analysis）+ `tests/test_olist_kpi.py`（13 测试）。产物落 `data/processed/olist_kpi/`：overall_kpi.json、drilldown_by_{state,weight,month}.csv、weight_time_relationship.csv、review_cross.json、olist_kpi_report.md。

**关键实测数字（n=96282）**：
- 真实准时交付率 **91.87%**、延迟率 8.13%；平均履约 12.57 天 / 出库响应 2.8 天 / 在途 9.33 天
- 延迟 Top 州：AL 23.9% / MA 19.8% / PI 16.1% / CE 15.3% / SE 15.3%（巴西东北部偏远州，履约 19–24 天，符合真实地理）

- 评分交叉：延迟组均分 2.57 / 差评率 54% vs 准时组 4.30 / 差评率 9.2%，gap 1.73 分（延迟显著拉低满意度，PDCA 报告 P 段证据）

**口径（登记台账）**：重量段=订单内 item 重量之和(kg)，分 ≤0.5/0.5–1/1–3/3–10/>10kg，无重量数据归「未知」段不进时效分析；准时=实际送达≤预计送达（相等算准时，沿用 03 落盘的 is_late）；延迟 Top 州榜设订单数阈值 ≥100 避免小样本噪声；差评=订单评论均分≤2。
